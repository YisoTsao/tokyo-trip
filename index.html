DAY1

桃園 → 成田 → 富山

住宿｜富山站附近轉乘很緊

目標是當晚抵達富山，這天不排景點。

  1. 14:25–18:30桃園飛往成田
  2. 18:30–19:45入境、領行李、前往鐵路站（預估）
  3. 約 20:00–20:45成田機場搭京成 Skyliner 前往京成上野
  4. 約 20:45–21:10步行轉乘至 JR 上野站
  5. 約 21:10–23:10北陸新幹線前往富山（かがやき 519）
  6. 23:10 後前往飯店辦理入住、休息

轉乘風險

參考路線曾列出成田 20:00 出發、京成上野 20:45 抵達，再接上野 21:10 的北陸新幹線、23:10 抵達富山；這只是參考時刻，不代表你出發那天一定有同一班車。轉乘時間很緊，若飛機延誤或入境耗時較久，就可能錯過新幹線。

參考來源：ジョルダン（乘換案內）

當天注意

  • 飯店選富山站步行可到、可深夜入住的住宿。
  • 新幹線指定席最好預先確認。
  • 若不能接受錯過末班車的風險，較保險的做法是第一晚住成田／東京，第二天一早再去富山；但這會改變原本的住宿安排。
DAY2

黑部峽谷觀光小火車

住宿｜富山站附近部分路段營運

以黑部峽谷為當日主行程，避免再塞其他遠距離景點。

  1. 06:45–07:15起床、早餐
  2. 約 07:15–09:00富山站搭富山地方鐵道前往宇奈月溫泉（依當日列車銜接）
  3. 約 09:00–09:30步行至黑部峽谷鐵道宇奈月站、取票及候車
  4. 約 09:21–10:39觀光小火車前往欅平
  5. 約 10:40–14:00依當天開放範圍遊覽、拍照、午餐
  6. 約 14:37–15:54觀光小火車返回宇奈月
  7. 約 16:00–18:00返回富山市區
  8. 晚上富山晚餐、休息

班次說明

09:21 往程與 14:37 回程，是官方列出的 2026/10/1–11/23 班次之一，其他日期可能不同。官方也提醒，從富山地方鐵道轉乘小火車至少預留 20 分鐘。

來源：黑部峽谷鐵道官方時刻表

提醒

2026 年黑部峽谷鐵道是部分路段營運，不能假設所有步道與設施都開放。出發前請以官方網站確認可抵達的終點、回程班次及預約方式。

DAY3

富山 → 立山黑部 → 輕井澤

住宿｜輕井澤全程最緊湊

必須早出發、少停留，並確認最後一段交通。

  1. 06:00 前退房，前往富山站
  2. 約 06:00–07:00富山站前往立山站（依當日首班車調整）
  3. 約 07:00–08:00立山站購票、排隊及開始穿越路線
  4. 約 08:00–14:00依序穿越立山、美女平、室堂、大觀峰、黑部平、黑部水壩
  5. 約 14:00–15:30從扇澤前往信濃大町一帶
  6. 約 15:30–18:00從信濃大町轉乘鐵路前往長野或松本方向
  7. 傍晚至晚上轉乘北陸新幹線或其他適用路線前往輕井澤，抵達後入住

這一天的關鍵風險

立山黑部不是一條可以隨時快速通過的單一列車路線，而是多段交通工具串接。排隊、天候、停留時間都會影響抵達扇澤的時間；若錯過後續巴士或列車，就可能無法當晚抵達輕井澤。

時刻表版本

官方時刻表分為 2026/4/15–11/3 與 2026/11/4–11/30 兩種版本，11 月底出發請選後者。

來源：立山黑部阿爾卑斯山脈路線官方時刻表

DAY4

上高地：大正池 → 河童橋

住宿｜輕井澤交通時間長

景色很值得，但從輕井澤往返上高地會花很多交通時間。

  1. 約 05:00–05:30從輕井澤出發
  2. 清晨至上午經長野／松本方向轉乘，前往上高地入口巴士站（依當日交通安排）
  3. 約 09:00–09:30抵達大正池附近，開始步行
  4. 約 09:30–11:30大正池 → 田代池／田代濕原 → 梓川沿岸步道
  5. 約 11:30–13:00河童橋周邊、午餐、拍照
  6. 約 13:00–14:00依體力在河童橋附近散步
  7. 下午搭巴士離開上高地，轉乘鐵路返回輕井澤
  8. 晚上輕井澤晚餐、休息

關於時間

步行段可依現場步道狀況和體力調整。這份時間表是行程目標，不是已核實的轉乘班次；由輕井澤往返上高地，實際上可能需要更早出發，而且山區巴士班次有限。上高地每年約 11 月中旬封山，11 月底請先確認巴士是否仍在營運。

特別建議

如果立山黑部和上高地都是必去景點，這兩天連續安排會很累。較穩妥的住宿點通常是松本或長野；但你指定第 3、4 晚住輕井澤，因此先保留原安排。

DAY5

輕井澤 → 東京，開始購物

住宿｜東京輕鬆日

上午留在輕井澤，下午移動至東京。

  1. 08:00–09:00早餐、退房
  2. 09:00–11:00舊輕井澤銀座散步或咖啡店
  3. 11:00–13:00輕井澤 Prince Shopping Plaza Outlet、午餐
  4. 13:00–15:00回住宿取行李、前往輕井澤站
  5. 下午搭北陸新幹線前往東京（車程約 1 小時上下，依車種而異）
  6. 16:00–18:00東京飯店入住
  7. 晚上新宿或澀谷購物、晚餐
DAY6

東京完整購物日

住宿｜東京一至兩區就好

選一至兩個購物區，避免整天花在交通上。

  1. 09:00–12:00新宿：百貨、藥妝、電器或服飾
  2. 12:00–13:00午餐
  3. 13:00–16:00澀谷：Shibuya Scramble Square、PARCO、周邊商店
  4. 16:00–18:00依需求加逛原宿、表參道，或回飯店放戰利品
  5. 18:00–20:00晚餐
  6. 20:00 後自由活動、整理行李

換區小提示

偏好精品與百貨，可以把澀谷改成銀座；以動漫、電玩、模型為主，可以把部分時間改為池袋或秋葉原。

DAY7

東京 → 成田機場 → 桃園

回程｜14:35 起飛

預留足夠的機場交通與報到時間。

  1. 07:30–08:30早餐、退房
  2. 約 09:00從東京市區出發前往成田機場
  3. 約 10:30–11:30抵達機場、辦理報到及行李托運
  4. 11:30–13:30安檢、出境、候機
  5. 14:35–17:45成田飛往桃園

機場交通

抵達成田的目標時間抓在起飛前約 3 小時，依實際住宿地點選擇 Skyliner、成田特快 N'EX 或機場巴士。
